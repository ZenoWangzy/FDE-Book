# 附录 A：dsh 安装说明

本附录内容尚未在课堂环境实测。现有研究记录区分了官方裸装 dsh 和本课程需要的 VectA 配置；它不能代替教师对课堂电脑、账号和实训步骤的开课前验证。学生可用本附录了解已记录的启动方式和当前边界。

## 官方裸装启动方式

研究记录列出的普通使用者启动方式要求 Node.js 不低于 24.9.0。安装后可在终端检查 Node.js 和 npm 版本，再启动本机 Web 界面：

~~~sh
node -v
npm -v
npx @deepseek-ai/dsh web
~~~

研究记录说明，界面默认地址为 http://127.0.0.1:3080。以上只启动官方裸装 dsh，不会安装 VectA 登录插件，也不会自动配置课堂所需的 profile；它不是完整的课堂安装包。

## VectA 课堂配置的已知边界

本课程的 dsh 配置需要 VectA 登录插件和预先配置的 profile。研究记录显示，登录包以私有软件包交付，尚无发给学生的一键安装包。配置把本地文件、命令、网页、技能和子 Agent 等工具设为禁用；裸装 dsh 的能力不能直接当作课堂登录后的可用功能。研究记录也没有证明学员登录和对话已在生产环境端到端跑通。

问题单 10 要求开课前验证 VectA 账号登录、账号额度、演示账套实训，以及前 6 周所需的本机工具。以下事项尚待验证，验证后再补入可照做的课堂步骤：

- 确定课堂使用的 dsh 版本、VectA 登录包和 profile，并验证教师预装流程。
- 在目标课堂环境端到端验证学员使用 VectA 账号登录和对话。
- 补上学员账号的开通、登录和权限操作说明。
- 准备并验证独立的非生产课堂环境、演示账套及其账号绑定方式，确保实训不接触客户生产数据。
- 核实前 6 周实训需要的本机工具在课堂 profile 中是否可用，以及相应的权限和操作步骤。
- 实测学员是否使用 VectA 账号额度完成课程调用。
- 从演示账套取一条实际的虚拟业务链，核对或替换第 7–12 章使用的课堂数据集；完成后移除相关待核标注。
