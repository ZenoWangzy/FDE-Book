# 巷口小灶：日常经营材料

巷口小灶是一家社区餐馆。店里用微信群接订餐，店员把确认的菜和份数记在本子上。进货数量写在手写单上。下面是老板和店员的访谈，以及连续三天的订餐记录和进货单文字稿。

## 一、访谈记录

### 老板访谈

| 轮次 | 问 | 答 |
|---|---|---|
| 1 | 店里平常怎么接订餐？ | 主要看微信群。有人发菜和份数，我们看见了就回一句。 |
| 2 | 谁负责看群？ | 我和小林都会看。午饭忙的时候谁有空谁回。 |
| 3 | 你们怎样把订单交给厨房？ | 店员把菜和份数抄在白板上，厨房照着做。 |
| 4 | 顾客来取时怎么确认？ | 顾客说称呼，我们对一下白板，做好的就给他。 |
| 5 | 三天里哪天最忙？ | 午饭都忙，差不多十一点半到十二点半。 |
| 6 | 周二一共做了多少份？ | 我记得是十八份。群里最后确认的都算上了。 |
| 7 | 三天的订餐都做了吗？ | 只要我们回了确认，一般都做。改菜的话，店员会再看一眼群。 |
| 8 | 进货数量记在哪里？ | 送来的时候写一张小单，晚上有时把剩下的数写在单子背面。 |
| 9 | 你现在最想改善什么？ | 我不懂这些技术。有人跟我说可以弄个 AI，我想先听听店里什么地方最费劲。 |
| 10 | 你觉得现在的记录够不够用？ | 有问题时能翻到群和本子，不过有时要翻好几处。 |

### 店员访谈一：小林

| 轮次 | 问 | 答 |
|---|---|---|
| 1 | 你上班时先做什么？ | 先看群里有没有新单，再把已经确认的菜抄到白板上。 |
| 2 | 什么时候最难顾上群？ | 十一点半以后，厨房也在叫菜，手机消息一下子来几条。 |
| 3 | 回消息一般要多久？ | 手上没事就很快。有时做完手里的事再回。 |
| 4 | 你会不会记下发消息的时间？ | 群里有时间，我抄单时不写。顾客后来问，我才回去翻。 |
| 5 | 顾客发两次一样的话会怎样？ | 有时是手机卡了又发一遍。我忙起来可能两条都抄。 |
| 6 | 你怎么知道第二条不是加单？ | 看他有没有写“再加”。没写的话，我通常还是先做，免得少做。 |
| 7 | 顾客临时改菜呢？ | 我会在白板上改，有时先前那行没擦干净。 |
| 8 | 做好的餐怎么交给顾客？ | 顾客报称呼，我对一下菜和份数，再把那行划掉。 |
| 9 | 你觉得哪里容易出错？ | 忙时容易漏看一条，或者不确定顾客是不是又发了一次。 |

### 店员访谈二：阿琴

| 轮次 | 问 | 答 |
|---|---|---|
| 1 | 你负责哪部分？ | 我常帮着收货、记数量，也会在午饭时接单。 |
| 2 | 收货时怎么记？ | 看送来的东西，在纸上写品名和斤数。没有统一格式。 |
| 3 | 进货单每天都会留吗？ | 我会先夹在账本里，晚上把余量写在背面。 |
| 4 | 这三天开始前有多少米和猪肉？ | 我翻过前一天的本子，开始时大米两斤、猪肉一斤。 |
| 5 | 菜里大概用多少米和肉？ | 肉燥饭一份用米二两、猪肉一两半。素菜饭用米二两。猪肉汤面用猪肉一两半。 |
| 6 | 你们会记招待餐或损耗吗？ | 这三天没有另外记。白板上的订餐都做了，顾客也都取走了。 |
| 7 | 盘点数写在哪里？ | 最后一张进货单背面。我当时数完就写上去了。 |
| 8 | 做菜时用的数量会记下来吗？ | 不会一份一份记。厨房按白板做，菜的用量按平常的份量。 |
| 9 | 你觉得这些纸好找吗？ | 认识自己的字就找得到，别人有时要问我。 |

## 三、手写进货单文字稿

### 进货单 A：10月12日

纸面内容：大米，4斤；猪肉，2斤。收货后夹入账本。

### 进货单 B：10月13日

纸面内容：大米，3斤；猪肉，2斤。收货后夹入账本。

### 进货单 C：10月14日

纸面内容：大米，3斤；猪肉，2斤。收货后夹入账本。背面写着“晚上盘点：大米5斤，猪肉2.7斤”。

阿琴回忆，10月12日开工前有大米2斤、猪肉1斤。她说三天记录中的每份肉燥饭用大米0.2斤、猪肉0.15斤；每份素菜饭用大米0.2斤；每份猪肉汤面用猪肉0.15斤。她没有另记这三天的损耗或招待餐。
