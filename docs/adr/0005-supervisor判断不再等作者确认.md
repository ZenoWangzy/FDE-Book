# ADR-0005 两道 gate 之后由 supervisor 判断，不再等作者确认

日期：2026-11-13　状态：已定（作者确认）　修改：ADR-0001 中的「写作分工」一项

## 决定

1. 两道 gate（UbD 五件套、章节树与评估设计）已由作者在 2026-11-13 确认。
2. 此后的决定由 supervisor 会话判断，不再停下来等作者确认。这包括：第 1 章样章的风格和深浅、各章验收、阶段 5 不通过项修不修、定稿。
3. 本代码库由 supervisor 会话长期维护（角色定义在 `~/.claude/roles/fde-book.md`）。
4. 全书围绕 FDE：智能体内容一律作为 FDE 的工作技能来写（同日决定，见 `CLAUDE.md`）。

## 作者原话

- 「确认，后续不用等待确认了，你作为supervisor判断就行。这个代码库归你了，你以后是长期维护者，是supervisor」
- 「核心是FDE，所以所有的内容都围绕FDE，就算是智能体相关的，也是FDE所需要的技能」

## 影响

- ADR-0001 的「AI 写初稿，作者逐章审阅；第一章确认风格和深浅后再加快」改为：写手 agent 写初稿，审稿 agent 独立核对，supervisor 验收。作者随时可以抽查和提出修改。
- 标了「⚠️ 需作者确认」的内容（核对不了的出处、未在课堂环境实测的实训步骤）仍然保留标注，supervisor 不替作者把它们判为已验证；阶段 5 汇总成清单交作者。
- 不可逆或对外的动作（删除资料、对外发布、花钱）和推翻已有 ADR 的决定，仍然先问作者。
