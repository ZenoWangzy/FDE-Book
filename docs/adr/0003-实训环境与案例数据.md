# ADR-0003 实训环境与案例数据

日期：2026-11-13　状态：已定（作者确认）

## 决定

1. **实训环境**：12 周的实训都用 DeepSeek Harness（dsh），学员用 VectA 账号登录，调用额度走 VectA 账号的额度，不另配 DeepSeek API key。
   - 前 6 周：智能体基础操作。
   - 后 6 周：在 VectA 演示账套上做贯穿案例的业务实训。
2. **dsh 接入不是现在的工作**：dsh 和 VectA 的接入（端到端跑通、学员开户、演示账套准备）等开课前再做。现在只在规划里加一条开课前验证（问题单 10）。教材照最终形态写。
3. **费用**：以后再定。
4. **案例数据**：不做脱敏。教材里的数据一律取自 VectA 演示账套：演示账套里本来就是虚拟数据，只有生产账套里才是客户真实数据。教材不使用生产账套的任何数据。

## 作者原话

- 「dsh后面做就好了，又不是现在就用，加一个验证就好了。费用后面再说。」
- 「dsh都用vecta的账号额度。」
- 「不脱敏，用虚拟数据就可以了，现在演示账套都是假数据。本来生产账套才是真数据。」

## 影响

- 问题单 02 列出的缺口（接入 VectA 后本机工具被关闭、生产端到端未验证、学员开户、演示账套）都转为开课前验证项，不阻塞写教材。
- 写案例章节和实训时，单据、数量、金额都从演示账套或已有的课堂合成数据中取，不从生产账套或客户原始资料中取。
