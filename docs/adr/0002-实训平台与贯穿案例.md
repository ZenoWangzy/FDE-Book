# ADR-0002 实训平台用 DeepSeek Harness + VectA，贯穿案例用作者的真实项目

日期：2026-11-13　状态：已定（作者确认）　取代：ADR-0001 中的「实训工具」和「贯穿案例」两项

## 决定

1. **实训平台**：不用 Dify 和 Coze（作者原话：「coze和dify都死了」）。实训用 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（命令行 `dsh`），并尽量通过作者自己的产品 VectA 来用。VectA 会封装 DeepSeek Harness，`@vecta/dsh-vecta-auth` 已支持用 VectA 账号登录 dsh。
2. **贯穿案例**：不虚构公司，以作者的真实项目为准：VectA 为水果供应链企业做的部署。现有素材见 `references/own-vecta/`（作者本人的 FDE 课件讲稿）和 VectA 仓库 `docs/`。

## 理由

- 学生用作者实际在用的产品，学到的就是真实的 FDE 工作方式。教材和产品互相印证。
- 真实项目比虚构公司更可信，也能直接复用作者已有的课件。

## 影响

- 学员没有编程基础，而 dsh 是命令行工具。教材要单独讲安装和基本操作，降低上手门槛（问题单 02 调研具体做法）。
- 学员账号要绑定演示账套，不能接触客户的生产数据。
- 真实案例中的客户名称、人员和金额哪些能写进教材，需要和作者确认（问题单 04）。
- 作者自己的课件和 VectA 文档是作者的原创，不需要按借鉴资料标注出处；但其中引用的第三方资料仍要注明出处。
