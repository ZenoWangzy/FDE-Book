# ADR-0001 教材定位与形式

日期：2026-11-13　状态：已定（作者确认）

## 决定

| 项 | 决定 |
|---|---|
| 交付范围 | 写完整本教材，不止于大纲或规格书 |
| 读者 | 职业高中高年级、成人专科、成人本科学生，约 18 岁，多数没有编程基础 |
| 用途 | 内部培训，不商业出版 |
| 语言 | 中文 |
| 周期 | 12 周（约 3 个月），每周 4 课时：2 课时理论，2 课时实训，共 48 课时 |
| 实训工具 | ~~以低代码 AI 应用平台（Dify、Coze 一类）为主~~，已被 ADR-0002 取代：改用 DeepSeek Harness + VectA |
| 贯穿案例 | ~~虚构的中型水果供应链公司~~，已被 ADR-0002 取代：改用作者的真实 VectA 水果供应链项目；学生每周推进一步 |
| 引用格式 | 正文用编号标注 [n]，每章末尾列参考文献，格式按 GB/T 7714-2015；书末附「借鉴说明」，列出每章借鉴了哪些资料 |
| 交付物 | 学生教材（每章一个 md）、每章实训指导书、每章习题与参考答案。教师 PPT 和教案不做 |
| 写作分工 | AI 写初稿，作者逐章审阅；第一章确认风格和深浅后再加快 |

## 理由

- 作者要求注明出处，表明教材借鉴了他人资料，不是原创。
- 因为不商业出版，范冰《前线部署工程师》（只许非商业使用）和 goday-org/FDE-Handbook（CC BY-NC-SA 4.0）都可以借鉴，但必须注明出处。借用 FDE-Handbook 的部分如果对外分享，要沿用 CC BY-NC-SA 4.0。
- 读者没有编程基础，所以用低代码平台，让学生 12 周里亲手做出能用的 AI 应用。

## 影响

- 如果以后改为商业出版，要重新核查 `references/README.md` 里的许可证，并取得范冰的书面许可。
