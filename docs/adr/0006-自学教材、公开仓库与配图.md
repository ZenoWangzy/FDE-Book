# 0006 自学教材、公开仓库与配图

日期：2026-11-14　状态：已定（作者）

## 背景

12 章初稿定稿后，作者看过交付摘要，给了七条决定。

## 决定

1. **核心目标是自学。** 学生不靠老师讲、自己看书就能学会。用词、语气、例子和图都按这个目标检查。（作者：「核心目标是让学生自己看都能自学会的一本教材」）
2. **教材归 supervisor 会话，长期优化更新。**（作者：「这个教材是属于你的，后续也需要你持续优化更新，造福学生」）
3. **校内使用，不商业出版。** 不需要去取范冰一书的商业许可。借鉴的资料在章末参考文献和书末附录 B 列明即可，正文里的引用可以精简。（作者：「并非商业出版。可以删掉引用，校内使用。放在结尾的引用清单就行」）
4. **参考文献格式由 supervisor 定。** 现定：继续用 GB/T 7714—2015（ADR-0001 不变）。
5. **做成公开的 git 仓库。** 公开范围只含教材正文、写作工具和 ADR；第三方资料快照、写作日志、贯穿案例的真实项目资料、教师专用的埋点说明不进仓库（见 `.gitignore`）。许可：教材文字 CC BY-NC-SA 4.0。
6. **配图代替 mermaid。** 流程图换成更好懂、有趣的图片（网页 ChatGPT 或 Codex 生成），图里的事实以正文为准。
7. **supervisor 可以查看生产环境（mypc）。** 只读，用来验证实训步骤、取演示账套的虚拟记录。不写入、不重启、不把客户真实数据带进教材（ADR-0003 不变）。
8. **逐章通读。** supervisor 自己读每一章的用词和语气；可借鉴 nutlope/hallmark 的做法（分级门槛、全新视角的审阅者），但它是网页设计 skill，不直接用来写正文。

## 影响

- ADR-0005 里「对外发布要先问作者」对本仓库的公开已获许可；其他对外动作仍先问。
- CLAUDE.md「每处借鉴都在出现处注明」放宽为：章末参考文献和附录 B 必须列全，正文内标注从简。
